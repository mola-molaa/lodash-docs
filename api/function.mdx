<Heading level="1">
    函数方法 API
</Heading>

<Paragraph>
    Lodash 提供了丰富的函数操作方法，包括柯里化、节流、防抖等。
</Paragraph>

<Divider blockColor="light_grey" />

<Heading level="2">
    柯里化与偏函数应用
</Heading>

<Heading level="3">
    \_.curry
</Heading>

<Paragraph>
    创建一个函数，该函数接收 func 的参数，如果参数数量足够则执行 func，否则返回一个继续接收剩余参数的函数。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var abc = function(a, b, c) {</Mark>
<Mark color="grey">  return [a, b, c];</Mark>
<Mark color="grey">};</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">var curried = \_.curry(abc);</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">curried(1)(2)(3);</Mark>
<Mark color="grey">// => [1, 2, 3]</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">curried(1, 2)(3);</Mark>
<Mark color="grey">// => [1, 2, 3]</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">curried(1, 2, 3);</Mark>
<Mark color="grey">// => [1, 2, 3]</Mark>
</Paragraph>

<Heading level="3">
    \_.curryRight
</Heading>

<Paragraph>
    类似 <Mark>curry</Mark>，但从右到左柯里化参数。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var abc = function(a, b, c) {</Mark>
<Mark color="grey">  return [a, b, c];</Mark>
<Mark color="grey">};</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">var curried = \_.curryRight(abc);</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">curried(3)(2)(1);</Mark>
<Mark color="grey">// => [1, 2, 3]</Mark>
</Paragraph>

<Heading level="3">
    \_.partial
</Heading>

<Paragraph>
    创建一个函数，调用 func 时预先填充部分参数。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">function greet(greeting, name) {</Mark>
<Mark color="grey">  return greeting + ' ' + name;</Mark>
<Mark color="grey">}</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">var sayHelloTo = \_.partial(greet, 'hello');</Mark>
<Mark color="grey">sayHelloTo('fred');</Mark>
<Mark color="grey">// => 'hello fred'</Mark>
</Paragraph>

<Heading level="3">
    \_.partialRight
</Heading>

<Paragraph>
    类似 <Mark>partial</Mark>，但填充右侧参数。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">function greet(greeting, name) {</Mark>
<Mark color="grey">  return greeting + ' ' + name;</Mark>
<Mark color="grey">}</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">var greetFred = \_.partialRight(greet, 'fred');</Mark>
<Mark color="grey">greetFred('hi');</Mark>
<Mark color="grey">// => 'hi fred'</Mark>
</Paragraph>

<Divider blockColor="light_grey" />

<Heading level="2">
    函数节流与防抖
</Heading>

<Heading level="3">
    \_.throttle
</Heading>

<Paragraph>
    创建一个节流函数，在 wait 秒内最多执行一次 func。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">\_.throttle(function() {</Mark>
<Mark color="grey">  console.log('throttled');</Mark>
<Mark color="grey">}, 1000);</Mark>
</Paragraph>

<Heading level="3">
    \_.debounce
</Heading>

<Paragraph>
    创建一个防抖函数，延迟执行 func 直到 wait 毫秒后不再调用。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">\_.debounce(function() {</Mark>
<Mark color="grey">  console.log('debounced');</Mark>
<Mark color="grey">}, 1000);</Mark>
</Paragraph>

<Divider blockColor="light_grey" />

<Heading level="2">
    函数绑定
</Heading>

<Heading level="3">
    \_.bind
</Heading>

<Paragraph>
    创建一个函数，在指定 this 绑定下调用 func。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var greet = function(greeting, punctuation) {</Mark>
<Mark color="grey">  return greeting + ' ' + this.name + punctuation;</Mark>
<Mark color="grey">};</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">var object = { 'name': 'fred' };</Mark>
<Mark color="grey">var bound = \_.bind(greet, object, 'hi');</Mark>
<Mark color="grey">bound('!');</Mark>
<Mark color="grey">// => 'hi fred!'</Mark>
</Paragraph>

<Heading level="3">
    \_.bindAll
</Heading>

<Paragraph>
    绑定对象的方法到对象实例上，保持 this 指向。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var view = {</Mark>
<Mark color="grey">  'label': 'docs',</Mark>
<Mark color="grey">  'onClick': function() {</Mark>
<Mark color="grey">    console.log('clicked ' + this.label);</Mark>
<Mark color="grey">  }</Mark>
<Mark color="grey">};</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">\_.bindAll(view, ['onClick']);</Mark>
<Mark color="grey">// 现在 view.onClick 的 this 总是 view</Mark>
</Paragraph>

<Divider blockColor="light_grey" />

<Heading level="2">
    函数组合
</Heading>

<Heading level="3">
    \_.flow (pipe)
</Heading>

<Paragraph>
    从左到右组合函数，类似 Unix 管道。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">function square(n) { return n * n; }</Mark>
<Mark color="grey">function add5(n) { return n + 5; }</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">var add5ThenSquare = \_.flow(add5, square);</Mark>
<Mark color="grey">add5ThenSquare(2);</Mark>
<Mark color="grey">// => 49 (2 + 5 = 7, 7 * 7 = 49)</Mark>
</Paragraph>

<Heading level="3">
    \_.flowRight (compose)
</Heading>

<Paragraph>
    从右到左组合函数，类似函数组合。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">function square(n) { return n * n; }</Mark>
<Mark color="grey">function add5(n) { return n + 5; }</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">var squareThenAdd5 = \_.flowRight(add5, square);</Mark>
<Mark color="grey">squareThenAdd5(2);</Mark>
<Mark color="grey">// => 9 (2 * 2 = 4, 4 + 5 = 9)</Mark>
</Paragraph>

<Divider blockColor="light_grey" />

<Heading level="2">
    其他函数工具
</Heading>

<Heading level="3">
    \_.memoize
</Heading>

<Paragraph>
    创建一个会缓存结果的函数。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var fibonacci = \_.memoize(function(n) {</Mark>
<Mark color="grey">  return n < 2 ? n : fibonacci(n - 1) + fibonacci(n - 2);</Mark>
<Mark color="grey">});</Mark>
</Paragraph>

<Heading level="3">
    \_.negate
</Heading>

<Paragraph>
    创建一个否定 predicate 的函数。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">function isEven(n) { return n % 2 == 0; }</Mark>
<Mark color="grey">var isOdd = \_.negate(isEven);</Mark>
<Mark color="grey">\_.filter([1, 2, 3, 4, 5, 6], isOdd);</Mark>
<Mark color="grey">// => [1, 3, 5]</Mark>
</Paragraph>

<Heading level="3">
    \_.over
</Heading>

<Paragraph>
    创建一个函数，调用所有提供的函数并组合结果。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var func = \_.over([Math.max, Math.min]);</Mark>
<Mark color="grey">func(1, 2, 3, 4);</Mark>
<Mark color="grey">// => [4, 1]</Mark>
</Paragraph>

<Heading level="3">
    \_.overEvery (allPass)
</Heading>

<Paragraph>
    创建一个函数，当所有 predicate 都返回真值时返回 true。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var func = \_.overEvery([Boolean, isFinite]);</Mark>
<Mark color="grey">func(1);</Mark>
<Mark color="grey">// => true</Mark>
<Mark color="grey">func(null);</Mark>
<Mark color="grey">// => false</Mark>
</Paragraph>

<Heading level="3">
    \_.overSome (anyPass)
</Heading>

<Paragraph>
    创建一个函数，当任一 predicate 返回真值时返回 true。
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var func = \_.overSome([Boolean, isFinite]);</Mark>
<Mark color="grey">func(1);</Mark>
<Mark color="grey">// => true</Mark>
<Mark color="grey">func(null);</Mark>
<Mark color="grey">// => false</Mark>
<Mark color="grey">func(NaN);</Mark>
<Mark color="grey">// => false</Mark>
</Paragraph>

<Heading level="2">
    FP 模块中的函数方法
</Heading>

<Paragraph>
    在 FP 模块中，函数方法自动柯里化且参数重排：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var fp = require('lodash/fp');</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// 传统方式</Mark>
<Mark color="grey">\_.flow(add5, square)(2);</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// FP 方式</Mark>
<Mark color="grey">fp.flow(fp.add(5), fp.square)(2);</Mark>
<Mark color="grey">// => 49</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// 使用 Ramda 别名</Mark>
<Mark color="grey">fp.pipe(fp.add(5), fp.square)(2);</Mark>
<Mark color="grey">// => 49</Mark>
</Paragraph>

<Paragraph>
    <Mark>curry</Mark> 在 FP 模块中变为单参数：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var fp = require('lodash/fp');</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// FP 中的 curry 只接受 func 参数</Mark>
<Mark color="grey">var curriedAdd = fp.curry(function(a, b) {</Mark>
<Mark color="grey">  return a + b;</Mark>
<Mark color="grey">});</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">curriedAdd(1)(2);</Mark>
<Mark color="grey">// => 3</Mark>
</Paragraph>
