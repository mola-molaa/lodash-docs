<Heading level="1">
    FP 模块介绍
</Heading>

<Paragraph>
    <Mark bold>lodash/fp</Mark> 是 Lodash 的函数式编程模块，提供不可变、自动柯里化、iteratee-first data-last 风格的方法。
</Paragraph>

<Divider blockColor="light_grey" />

<Heading level="2">
    什么是 FP 风格？
</Heading>

<Paragraph>
    传统的 Lodash 方法使用 <Mark bold>data-first</Mark> 的参数顺序：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var _ = require('lodash');</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// 传统方式：数据在前</Mark>
<Mark color="grey">_.map([1, 2, 3], function(n) { return n * 2; });</Mark>
<Mark color="grey">// => [2, 4, 6]</Mark>
</Paragraph>

<Paragraph>
    FP 模块改为 <Mark bold>data-last</Mark> 的参数顺序，更适合函数组合：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var fp = require('lodash/fp');</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// FP 方式：数据在后</Mark>
<Mark color="grey">fp.map(function(n) { return n * 2; })([1, 2, 3]);</Mark>
<Mark color="grey">// => [2, 4, 6]</Mark>
</Paragraph>

<Divider blockColor="light_grey" />

<Heading level="2">
    主要特性
</Heading>

<Heading level="3">
    🔄 自动柯里化（Auto-currying）
</Heading>

<Paragraph>
    所有多参数方法都自动柯里化，可以逐步传入参数：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var fp = require('lodash/fp');</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// 柯里化示例</Mark>
<Mark color="grey">var add = fp.add(2);</Mark>
<Mark color="grey">add(3);</Mark>
<Mark color="grey">// => 5</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// 也可以一次传入所有参数</Mark>
<Mark color="grey">fp.add(2)(3);</Mark>
<Mark color="grey">// => 5</Mark>
</Paragraph>

<Heading level="3">
    🔀 参数重排（Rearg）
</Heading>

<Paragraph>
    方法参数被重新排序，将 iteratee 或 predicate 放在前面，数据放在最后：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">// 传统方式</Mark>
<Mark color="grey">_.filter([1, 2, 3, 4], function(n) { return n % 2 == 0; });</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// FP 方式</Mark>
<Mark color="grey">fp.filter(function(n) { return n % 2 == 0; })([1, 2, 3, 4]);</Mark>
<Mark color="grey">// => [2, 4]</Mark>
</Paragraph>

<Heading level="3">
    🛡️ 不可变操作（Immutable）
</Heading>

<Paragraph>
    会修改原数据的方法（如 <Mark>set</Mark>、<Mark>unset</Mark>、<Mark>assign</Mark>）在 FP 模块中会返回新对象，而不修改原对象：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var object = { 'a': { 'b': 2, 'c': 3 } };</Mark>
<Mark color="grey">var result = fp.set('a.b')(3)(object);</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">console.log(object);</Mark>
<Mark color="grey">// => { 'a': { 'b': 2, 'c': 3 } } - 原对象未修改</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">console.log(result);</Mark>
<Mark color="grey">// => { 'a': { 'b': 3, 'c': 3 } } - 返回新对象</Mark>
</Paragraph>

<Divider blockColor="light_grey" />

<Heading level="2">
    函数组合
</Heading>

<Paragraph>
    FP 模块非常适合函数组合，使用 <Mark>flow</Mark> 或 <Mark>flowRight</Mark>：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var fp = require('lodash/fp');</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">var square = function(n) { return n * n; };</Mark>
<Mark color="grey">var addOne = function(n) { return n + 1; };</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// 从左到右组合（pipe）</Mark>
<Mark color="grey">var pipeline = fp.flow(fp.filter(function(n) { return n % 2 == 0; }), fp.map(square), fp.take(2));</Mark>
<Mark color="grey">pipeline([1, 2, 3, 4, 5, 6]);</Mark>
<Mark color="grey">// => [4, 16]</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// 从右到左组合（compose）</Mark>
<Mark color="grey">var pipeline2 = fp.flowRight(fp.take(2), fp.map(square), fp.filter(function(n) { return n % 2 == 0; }));</Mark>
<Mark color="grey">pipeline2([1, 2, 3, 4, 5, 6]);</Mark>
<Mark color="grey">// => [4, 16]</Mark>
</Paragraph>

<Divider blockColor="light_grey" />

<Heading level="2">
    占位符（Placeholder）
</Heading>

<Paragraph>
    FP 模块支持占位符 <Mark>fp.__</Mark>，可以在部分应用中跳过某些参数：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark bold>javascript</Mark>
<Mark color="grey">var fp = require('lodash/fp');</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// 使用占位符</Mark>
<Mark color="grey">var add = fp.add(fp.__, 'b')('a');</Mark>
<Mark color="grey">// => 'ab'</Mark>
<Mark color="grey"></Mark>
<Mark color="grey">// fill 示例</Mark>
<Mark color="grey">var fill = fp.fill(fp.__, 2)(1, '*');</Mark>
<Mark color="grey">fill([1, 2, 3]);</Mark>
<Mark color="grey">// => [1, '*', 3]</Mark>
</Paragraph>
