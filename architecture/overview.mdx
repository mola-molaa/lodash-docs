<Heading level="2">
    FP 模块架构
</Heading>

<Paragraph>
    <Mark bold>lodash/fp</Mark> 是一个独立的模块，提供不可变、自动柯里化、iteratee-first data-last 风格的方法。
</Paragraph>

<Heading level="3">
    核心转换机制
</Heading>

<Paragraph>
    FP 模块的核心是 <Mark bold>_baseConvert.js</Mark>，它负责将标准 Lodash 方法转换为 FP 风格：
</Paragraph>

<BulletedList>
    自动柯里化（Curry）- 所有多参数方法自动转换为柯里化版本
    参数重排（Rearg）- 将 data-first 转换为 data-last 顺序
    参数固定（Fixed）- 限制 iteratee 的参数数量
    不可变操作（Immutable）- 修改对象时返回新对象而非修改原对象
</BulletedList>

<Heading level="2">
    CI/CD 流程
</Heading>

<Paragraph>
    Lodash 使用 GitHub Actions 进行持续集成和部署：
</Paragraph>

<BulletedList>
    <Mark bold>ci-node.yml</Mark> - 在多个 Node.js 版本上运行测试（Node 4-25）
    <Mark bold>ci-bun.yml</Mark> - 在 Bun 运行时上测试
    <Mark bold>ci-browsers.yml</Mark> - 在浏览器（Chrome、Firefox、WebKit）中测试
    <Mark bold>ci-docs.yml</Mark> - 测试文档生成
    <Mark bold>ci-dist-sync.yml</Mark> - 验证 dist 文件与源码同步
    <Mark bold>codeql.yml</Mark> - CodeQL 安全扫描
    <Mark bold>scorecards.yml</Mark> - 供应链安全评分
</BulletedList>
