<Heading level="1">
    Lodash v4.18.1
</Heading>

<Paragraph>
    <Mark bold>Lodash</Mark> 是一个现代化的 JavaScript 工具库，提供模块化、高性能的实用功能扩展。
</Paragraph>

<Paragraph>
    Lodash 导出为 <Mark bold>UMD</Mark> 模块格式，支持多种使用场景：
</Paragraph>

<BulletedList>
    浏览器环境直接使用
    Node.js 环境通过 require 引入
    AMD 模块加载器
    ES 模块（通过 lodash-es）
    FP 函数式编程风格（通过 lodash/fp）
</BulletedList>

<Divider blockColor="light_grey" />

<Heading level="2">
    主要特性
</Heading>

<ColumnList>
    <Column width="33%">
        <Heading level="3">
            🚀 高性能
        </Heading>
        <Paragraph>
            经过优化的数组、对象和字符串操作方法，提供比原生方法更快的执行速度。
        </Paragraph>
    </Column>
    <Column width="33%">
        <Heading level="3">
            🧩 模块化
        </Heading>
        <Paragraph>
            支持按需引入，可以按方法引入（cherry-pick）或按类别引入，减小打包体积。
        </Paragraph>
    </Column>
    <Column width="33%">
        <Heading level="3">
            🔧 功能丰富
        </Heading>
        <Paragraph>
            涵盖数组、对象、函数、字符串、数学等常用操作的 300+ 个实用方法。
        </Paragraph>
    </Column>
</ColumnList>

<Divider blockColor="light_grey" />

<Heading level="2">
    模块格式
</Heading>

<Paragraph>
    Lodash 提供多种构建版本和模块格式，满足不同项目需求：
</Paragraph>

<Table>
    <TableRow>
        <TableCell>
            <Mark bold>lodash</Mark>
        </TableCell>

    <TableRow>
        <TableCell>

<Heading level="2">
    为什么选择 Lodash？
</Heading>

<Paragraph>
    Lodash 让 JavaScript 开发变得更简单，通过消除处理数组、数字、对象、字符串等数据时的繁琐操作。Lodash 的模块化方法特别适合：
</Paragraph>

<BulletedList>
    遍历数组、对象和字符串
    操作和测试值
    创建组合函数
</BulletedList>
